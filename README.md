# MyProject

Навчальний проєкт для лабораторної роботи 6 «Налаштування CI/CD для автоматизації збору метрик, статичного аналізу коду і код-рев'ю».

Модуль `myproject.grades` рахує середній бал, медіану, оцінку ECTS і кількість зарахувань.

```bash
pip install -r requirements.txt
pytest
python -m myproject
```
